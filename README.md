# AI-Powered DPR Quality Assessment & Risk Prediction System

## 🚀 Overview
This project was developed for the **Smart India Hackathon 2025** to address Problem Statement **SIH25185** for the **Ministry of Development of North Eastern Region (MDoNER)**. 

The system automates the evaluation of Detailed Project Reports (DPRs), ensuring they meet government standards while using predictive analytics to forestall project delays and risks.

## ✨ Key Features
* **Automated Scoring:** Uses NLP to scan DPRs for required sections and compliance.
* **Risk Prediction:** ML models to forecast potential bottlenecks in regional development.
* **Interactive Dashboard:** Real-time visualization of project health and assessment metrics.

## 🛠️ Tech Stack
* **Frontend:** React.js / Next.js
* **Backend:** Node.js / Python (Flask/FastAPI)
* **AI/ML:** Scikit-learn, TensorFlow/PyTorch, NLTK/Spacy
* **Database:** MongoDB / PostgreSQL
